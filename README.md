A one-line roast of my own AI agent: it treats every deadline like a suggestion and every suggestion like a deadline. The joke wins against the brief because it is playful and self-deprecating rather than mean — the target is my own agent — and it finds a fresh angle instead of the stock gags about hallucinations, refusals, or confident wrong answers. The line is tight and symmetrical, the setup is short, and the punchline lands at the end.

## Run it

```sh
python3 main.py
```

This writes the roast to `/output/entry.txt`.
